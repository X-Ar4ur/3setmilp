# LBlock 局部分解与位序说明

## 采用的轮函数

内部状态按论文写作 \((X,Y)\)，各半 32 bit，nibble 从低到高编号为 0--7。一轮实现为：

\[
X' = P(S(X\oplus K))\oplus (Y\lll 8),\qquad Y'=X.
\]

数据 S 盒使用 \(S_0,\ldots,S_7\)，nibble 置换使用：

```text
输入 j:  0 1 2 3 4 5 6 7
输出 P:  2 0 3 1 6 4 7 5
```

密钥编排使用修订版规范纠正后的 \(S_8,S_9\)。官方修订说明明确指出原论文这两个表有排印错误，因此实现没有采用旧表。

## Algorithm 2 的 9 个局部边界

主论文把每轮写成 8 个 S 盒步骤和一次交换。为避免右半原地覆盖带来的读写依赖，实现采用以下等价电路：

1. 在第 0 个 core 前把右半公开循环左移 8 bit；
2. 第 \(j\) 个 core 计算 \(S_j(X_j\oplus K_j)\)，并异或到右半的 nibble \(P(j)\)；
3. 第 8 个局部步骤交换左右两半。

因此每轮仍有 9 个搜索边界。边界 0 的后缀模型包含右半旋转；边界 1--8 的输入状态已经处于旋转后的表示。BDPT 传播和 CBDP 后缀 MILP 使用完全相同的边界定义。

## 校验证据

- 全零明文、全零 80-bit 密钥得到 `c218185308e75bcd`；
- 明文 `0123456789abcdef`、密钥 `0123456789abcdeffedc` 得到 `4b7179d8ebee0c26`；
- 局部 keyed core 对全部 16 种 nibble 密钥做了穷举，所有被模型判为恒 0 或恒 1 的单项式都与直接计算一致；
- 服务器测试会把一轮 LBlock CBDP-MILP 与精确公开 BDPT 传播逐输出位比较。

规范来源：修订版 [LBlock: A Lightweight Block Cipher](https://eprint.iacr.org/2011/345)。
