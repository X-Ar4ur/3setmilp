## 2. 项目背景

本项目用于从零实现并验证三子集比特可分性（Bit-based Division Property using Three Subsets，BDPT）的 MILP 辅助搜索方法。

项目当前只有以下三篇参考文献：

1. *Bit-Based Division Property and Application to Simon Family*：提出 CBDP 和 BDPT，给出基本传播规则、SIMON32 精确传播结果和 lazy propagation。
2. *MILP-aided Method of Searching Division Property Using Three Subsets and Applications*：本项目的主要复现对象，提出基于 CBDP-MILP 可达性查询的 BDPT 剪枝和停止算法。
3. *Exploring Secret Keys in Searching Integral Distinguishers Based on Division Property*：主论文的后续改进工作，仅用于理解局限和后续扩展，不纳入本次基线实现。

独立复现的目的不是立即构造通用密码分析框架，而是回答以下问题：

- 论文描述是否足以实现其核心算法？
- 实现能否得到论文报告的中间传播状态和最终积分区分器？
- 论文中是否存在会影响结果的公式错误、符号歧义或未说明实现细节？
- 算法在现代 Gurobi 环境中的时间、内存和扩展性是否适合作为 EasyBC 新功能的基础？

只有在独立实现通过验收后，才单独评估迁入 EasyBC 的工作。

## 3. 项目目标与非目标

### 3.1 项目目标

1. 实现 CBDP division trail 的 MILP 可行性判断。
2. 实现 BDPT 的集合语义、基本传播规则、S-box 传播、化简和奇偶抵消。
3. 实现主论文的 Prune K、Prune L、fast propagation 和三条停止规则。
4. 实现主论文 Algorithm 1 `SCBDP` 和 Algorithm 2 `BDPT`。
5. 为以下分组密码建立论文一致的局部操作划分和 CBDP-MILP 模型：
   - SIMON32、SIMON64；
   - SIMECK 系列中论文涉及的实例；
   - PRESENT；
   - RECTANGLE；
   - LBlock。
6. 复现论文 Tables 3–6 及相关文字结果。
7. 建立小规模穷举验证器，使核心传播和低轮实验不只依赖论文结果。
8. 输出完整复现报告，记录一致结果、差异、论文疑点、运行环境和性能数据。
9. 提供适合服务器运行的非交互实验入口、配置和结构化结果文件。

### 3.2 非目标

- 直接集成或修改 EasyBC；

## 4. 核心术语与语义

### 4.1 CBDP

CBDP 使用向量集合 \(K\) 描述单项式求和结果：若目标指数向量能够支配某个 \(k\in K\)，结果为 unknown；否则结果为 0。

本项目中的 CBDP-MILP 只回答一个可达性问题：给定输入向量 \(k\)、密码后缀 \(E\) 和目标单位向量 \(e_m\)，是否存在 division trail

\[
k \xrightarrow{E} e_m.
\]

### 4.2 BDPT

BDPT 状态表示为 \(D_{K,L}^{1^n}\)：

- 若指数向量支配 \(K\) 中某个元素，对应求和结果为 unknown；
- 否则若指数向量属于 \(L\)，对应求和结果为 1；
- 其他情况对应求和结果为 0。

同一输出向量由多个 \(L\) 向量传播得到时，按出现次数模 2 合并，即使用奇偶抵消而不是普通集合并集。

### 4.3 MILP 辅助 BDPT

主论文并未将完整 BDPT 一次性编码为单个 MILP。核心流程是：

1. 将密码轮函数拆分为若干较小的局部函数 \(Q_{i,j}\)。
2. 使用 CBDP-MILP 检查当前 \(K,L\) 向量能否通过剩余密码到达目标位。
3. 若 \(K\) 中存在可达向量，依据停止规则返回 unknown。
4. 删除 \(K,L\) 中所有无法到达目标位的向量。
5. 若过滤后的 \(L\) 为空，返回 balanced/0。
6. 对幸存的 \(L\) 通过下一个局部函数进行精确 BDPT 传播。
7. 完成全部传播后仍未提前返回，则结果为 1。

## 5. 用户场景

### 5.1 论文复现者

复现者能够通过一条明确命令运行某个论文实验，并得到：

- 输入活动/常量模式；
- 轮数和目标输出位；
- 返回值 `zero`、`one` 或 `unknown`；
- 每个局部步骤的 \(|K|\)、\(|L|\)；
- MILP 查询次数、命中缓存次数、求解时间和总运行时间；
- 与论文期望结果的自动比较。

### 5.2 算法审计者

审计者能够单独运行基本操作、局部 S-box 或低轮密码测试，检查：

- 传播输入和输出集合；
- dominance 化简过程；
- \(L\) 集合的奇偶抵消；
- MILP 可行解或不可行结论；
- 论文公式与实际实现的对应关系。

### 5.3 服务器实验执行者

服务器用户能够：

- 使用现有 Gurobi License 非交互运行实验；
- 按密码、轮数和目标位拆分任务；
- 安全地重跑中断实验；
- 汇总不同任务的结构化结果；
- 不依赖桌面界面或本地绝对路径。

## 6. 功能需求

### 6.1 数学与数据结构模块

#### FR-CORE-001 位向量表示

- 使用不可变、可哈希的紧凑表示保存 bit vector。
- 支持按位访问、Hamming weight、单位向量、置位/清位和格式化。
- 内部建议使用 Python `int` 作为 bitset，输入输出边界提供显式转换。
- 位序约定必须集中定义，禁止各密码模块自行猜测。

#### FR-CORE-002 偏序关系

- 实现论文使用的逐位支配关系。
- 明确区分“逐位大于等于”“严格支配”和“不等于”。
- 针对初始 \(K\) 的生成编写独立测试，避免符号 OCR 或排版歧义进入实现。

#### FR-CORE-003 BDPT 状态

- 状态包含维度、\(K\) 和 \(L\)。
- 支持复制、规范化、集合规模统计和稳定序列化。
- 默认保持不可变边界，局部性能敏感代码可使用受控可变集合。

#### FR-CORE-004 Reduce0 与 Reduce1

- `Reduce0(K)` 删除被其他 \(K\) 向量覆盖的冗余向量。
- `Reduce1(K, L)` 删除已经落入 unknown 区域的 \(L\) 向量。
- 化简前后必须保持 BDPT 对所有指数向量的语义等价。

#### FR-CORE-005 奇偶合并

- 多个传播分支生成相同 \(L\) 向量时，按模 2 合并。
- 提供对称差式插入接口，避免误用普通 `set.update()`。

### 6.2 局部 BDPT 传播模块

#### FR-BDPT-001 Copy

实现原始论文给出的 Copy 传播，并分别处理 \(K\) 和 \(L\)。

#### FR-BDPT-002 AND

实现 AND 压缩传播，验证允许输入模式和输出指数。

#### FR-BDPT-003 XOR

实现 XOR 压缩传播，并正确处理 \(L\) 的奇偶抵消。

#### FR-BDPT-004 XOR with Secret Key

实现主论文 BDPT Rule 4：保留原有 \(K,L\)，并依据相关 \(L\) 向量向 \(K\) 添加向量。

不得在基线版本中加入后续论文的 key-bypass 规则。

#### FR-BDPT-005 S-box

- 从 S-box 的 Boolean ANF 或等价真值表计算单个 \(L\) 向量的精确传播。
- 多个 \(L\) 输入分别传播，再对输出 \(L\) 按奇偶性合并。
- 输出执行 Reduce0 和 Reduce1。
- 支持 SIMON 局部 4-bit 核心、PRESENT/RECTANGLE/LBlock 的 4-bit S-box。

### 6.3 CBDP-MILP 模块

#### FR-MILP-001 求解器接口

- 首版使用 `gurobipy`。
- 支持创建变量、添加约束、固定输入输出、设置无目标可行性模型和读取状态。
- 将 Gurobi 状态统一映射为 `feasible`、`infeasible`、`error`。
- `TIME_LIMIT` 或其他未证明不可行的状态不得当作 balanced。

#### FR-MILP-002 基本操作模型

实现论文的 CBDP Copy、XOR、AND 模型，并通过枚举合法 division transition 进行验证。

#### FR-MILP-003 S-box 模型

- 根据 S-box 合法 CBDP transition 建立精确可行域。
- 第一优先级是正确性，不要求第一版复现论文所用的最小不等式数量。
- 可采用预生成不等式、凸包描述或带辅助变量的精确编码，但不得引入伪 transition 或排除合法 transition。

#### FR-MILP-004 密码后缀模型

- 能从任意局部函数边界 \((i,j)\) 建立到最终输出的密码后缀模型 \(\overline{E}_{i,j}\)。
- 支持完整轮和部分轮。
- 输入固定为给定向量，输出固定为目标单位向量 \(e_m\)。

#### FR-MILP-005 SCBDP

实现论文 Algorithm 1：

- 模型可行：返回 `unknown`；
- 模型严格不可行：返回 `zero`；
- 其他求解状态：返回错误，不给出密码分析结论。

#### FR-MILP-006 查询缓存

- 缓存键至少包含密码参数、局部边界、输入向量和目标输出位。
- 同一实验进程内避免重复构建、重复求解相同查询。
- 缓存不得跨不同位序约定或密码配置错误复用。

### 6.4 MILP 辅助 BDPT 搜索模块

#### FR-SEARCH-001 Prune K

对每个 \(k\in K\) 查询其到目标 \(e_m\) 的后缀可达性：

- 任一可达时立即返回 `unknown`；
- 不可达时安全删除该向量。

#### FR-SEARCH-002 Prune L

只保留能够通过密码后缀到达目标 \(e_m\) 的 \(L\) 向量。

#### FR-SEARCH-003 停止规则

实现并记录三种停止原因：

1. `K_REACHABLE`：结果 unknown；
2. `L_EMPTY`：结果 zero/balanced；
3. `FINAL_UNIT_L`：结果 one。

#### FR-SEARCH-004 Algorithm 2

- 按密码定义的局部函数顺序传播。
- 每个局部边界先执行后缀剪枝，再传播幸存的 \(L\)。
- 返回 `zero`、`one` 或 `unknown`，同时返回可审计的统计信息。

#### FR-SEARCH-005 多输出位实验

- 支持依次搜索全部输出位。
- 任务天然可按目标位并行，但第一版以串行正确性为主。
- 后续服务器并行应采用多进程或任务级并行，不在多个线程中共享非线程安全模型。

### 6.5 密码模型模块

#### FR-CIPHER-001 统一密码接口

每个密码模型至少提供：

- block size 和变体参数；
- 位序和状态布局说明；
- 局部函数序列及边界；
- 单个局部函数的精确 BDPT 传播；
- 对应 CBDP-MILP 约束生成；
- 轮密钥 XOR 的位置；
- 论文实验输入模式和预期输出。

接口只服务于本论文涉及的密码，不在本阶段设计通用密码描述语言。

#### FR-CIPHER-002 SIMON/SIMECK

- 实现 Feistel 状态布局、循环移位、AND、XOR 和轮密钥 XOR。
- 按论文将一轮拆为逐输出位核心操作和最终交换/密钥步骤。
- SIMON 4-bit 局部核心传播必须匹配论文附录 Table 7。
- 支持论文涉及的 SIMON32、SIMON64 和 SIMECK 参数。

#### FR-CIPHER-003 PRESENT/RECTANGLE

- 实现 4-bit S-box、线性置换和轮密钥 XOR。
- 按单个 S-box 或论文指定粒度划分局部函数。
- 保证字符串中输入/输出位的位置与内部位序之间可追踪转换。

#### FR-CIPHER-004 LBlock

- 实现左右分支、8 个 S-box、nibble 置换、分支 XOR 和交换。
- 按论文将每轮划分为 8 个局部 S-box 操作及最终交换。

### 6.6 实验与报告模块

#### FR-EXP-001 Table 3

复现 SIMON32 示例中的传播规模，至少记录每轮或论文对应局部边界的 \(|K|\)、\(|L|\)，并与论文“this paper”行比较。

#### FR-EXP-002 Table 4

复现 SIMON32、SIMON64 的输入模式和 balanced 输出位。报告中分别标明：

- Algorithm 2 直接覆盖的轮数；
- 论文引用额外技巧自然扩展的一轮；
- 实际实现是否包含该扩展步骤。

#### FR-EXP-003 Table 5

复现 PRESENT 和 RECTANGLE 的输入模式与 balanced 输出位。

#### FR-EXP-004 Table 6

复现 LBlock 的 16 轮和 17 轮积分区分器。

#### FR-EXP-005 SIMECK 文字结果

对论文正文中未完整列入表格的 SIMECK 结果，以密码变体、轮数、输入活动模式和输出 balanced 位形式记录。

#### FR-EXP-006 结构化输出

每次实验输出 JSON，至少包含：

- 代码版本或运行标识；
- Python、Gurobi 和平台版本；
- 密码、参数、轮数、输入模式和目标位；
- 结果及停止原因；
- \(K,L\) 规模轨迹；
- MILP 模型数、查询数、缓存命中数和求解时间；
- 峰值内存（可获取时）；
- 与论文期望值的比较结果。

## 7. 非功能需求

### 7.1 正确性

- 密码分析结论优先于性能。
- 所有关键公式都应有测试或独立推导依据。
- `infeasible` 才能证明 balanced；超时、异常和数值问题不能误报为 balanced。
- 所有论文结果必须能追溯到固定配置和日志。

### 7.2 可复现性

- 使用固定依赖声明和明确的 Python 版本范围。
- 实验命令不得依赖本地绝对路径。
- 在相同代码、配置和求解器设置下应得到相同密码分析结论。
- 性能数据允许因机器和 Gurobi 版本不同而变化。

### 7.3 可测试性

- 数学内核不依赖 Gurobi，便于快速单元测试。
- MILP 基本操作必须与枚举 transition oracle 对照。
- 低轮密码必须支持直接枚举或符号方法交叉验证。

### 7.4 性能与资源

- 使用整数 bitset，避免以 Python 元组保存大量向量。
- 对后缀 MILP 结构、查询和局部传播表进行缓存。
- 记录集合峰值和模型求解统计，定位状态爆炸来源。
- 第一版不为性能牺牲可审计性；优化需有前后基准和正确性回归测试。

### 7.5 编码与文档

- 源代码、配置和文档统一使用 UTF-8。
- 代码注释使用中文。
- 标识符可使用行业通用英文，公式符号尽量与论文一致。
- 后续 Git 提交信息和 Push 相关说明使用中文。

- 语言：Python 3.11 或项目实施时服务器可稳定支持的相近版本；
- MILP 求解器：Gurobi，通过 `gurobipy` 调用；

### 8.3 位向量表示

建议以 Python `int` 保存向量：

- 第 \(i\) 位通过 `(value >> i) & 1` 访问；
- 支配关系通过位运算判断；
- Hamming weight 使用 `int.bit_count()`；
- 集合作为 `set[int]`；
- 日志输出时再转换为固定宽度字符串或索引集合。

所有密码必须通过统一的 state-layout 层解释整数位，避免将论文从左到右的打印顺序直接等同于内部 bit index。

### 8.4 S-box 方案

1. 从真值表计算每个输出坐标的 ANF。
2. 根据论文定理生成单个输入 \(L=\{\ell\}\) 的输出 \(K,L\)。
3. 对所有可能的单向量输入预计算传播表。
4. 多向量输入通过查表、\(K\) 合并和 \(L\) 奇偶抵消完成。
5. 对 4-bit S-box 使用全枚举验证传播表。

CBDP-MILP 的 S-box transition 也从同一份 S-box 定义生成，避免手工维护两套不一致数据。

### 8.5 MILP 模型方案

- 每个状态位对应二进制变量。
- 按局部操作或整轮添加 CBDP transition 约束。
- 输入向量和目标单位向量通过等式固定。
- 模型无优化目标，只判断可行性。
- 对相同密码后缀可复用模型模板；固定条件可通过复制模型或受控更新实现。
- 调试模式允许导出 `.lp` 文件，但默认不批量生成大文件。

### 8.6 穷举验证方案

穷举验证分为两类：

1. **传播 transition 穷举**：枚举小函数输入指数和输出指数，验证局部 BDPT/CBDP 规则。
2. **低轮密码穷举**：对可承受的数据规模枚举明文集合和若干密钥，直接计算输出位 XOR，与算法的 zero/one 结论比较。

穷举不能证明所有大规模实验，但能及时发现位序、常量、轮密钥和传播规则错误。

## 10. 验收标准

### 10.1 第一里程碑：SIMON32 最小闭环

必须同时满足：

1. 基本 CBDP/BDPT 操作通过单元测试。
2. SIMON 4-bit 核心的单 \(L\) 传播与附录 Table 7 完全一致。
3. 论文中 \(Q_{1,15}\) 的两个输入 \(L\) 向量及奇偶抵消示例完全一致。
4. CBDP-MILP 基本操作与枚举合法 transition 一致。
5. SIMON32 低轮 MILP 可达性与独立枚举结果一致。
6. 复现 Table 3 的关键 \(|K|,|L|\) 轨迹；若有差异，能够定位到明确公式或实现假设。
7. 复现 Table 4 中 SIMON32 的 balanced 位。

未通过该里程碑前，不扩展到其他密码。

### 10.2 分组密码完整验收

- Table 4：SIMON32、SIMON64 结果一致；
- Table 5：两组 PRESENT 和一组 RECTANGLE 结果一致；
- Table 6：LBlock 16/17 轮结果一致；
- SIMECK 正文结果得到验证或形成有证据的差异报告；
- 每项实验均有配置、结构化日志和一条可重复执行命令；
- 对论文中的疑似错误不得通过硬编码期望输出绕过。

### 10.3 复现结论分级

最终报告使用以下结论之一：

1. **完全复现**：核心中间状态和最终结果均一致。
2. **条件复现**：修正有充分证据的论文排版错误或补充合理实现细节后结果一致。
3. **部分复现**：部分密码或部分表格一致，剩余差异已定位但无法消除。
4. **不可复现**：关键结果无法得到，且经过独立验证仍存在实质性矛盾。

运行时间不同本身不降低复现等级，除非资源消耗导致论文所称“实际可运行”的实验无法完成。

## 11. 已知风险与应对措施

| 风险 | 概率 | 影响 | 应对措施 |
|---|---:|---:|---|
| 论文公式存在排版错误 | 高 | 高 | 建立 `paper-errata.md`；用基本模型定义、密码语义和枚举三方验证 |
| 位序、左右分支或旋转方向误解 | 高 | 高 | 集中定义 state layout；使用轮函数已知向量和局部示例验证 |
| 初始 \(K,L\) 的严格支配符号有歧义 | 中 | 高 | 回查原始定义；对小维度明文多集直接计算所有单项式求和 |
| 多个 \(L\) 输出被错误地普通并集 | 中 | 高 | 封装奇偶插入接口；禁止业务代码直接更新 \(L\) 集合 |
| BDPT 集合爆炸 | 高 | 高 | 论文粒度拆分、及时剪枝、整数 bitset、传播表和统计监控 |
| MILP 查询数量过大 | 高 | 高 | 后缀模型复用、查询缓存、早停、按目标位拆分服务器任务 |
| S-box MILP 不等式不精确 | 中 | 高 | 与完整 transition 集逐项验证；正确性优先于约束数量 |
| 将 Gurobi 超时误判为不可行 | 低 | 高 | 只接受严格 `INFEASIBLE`；其他状态中止并记录 |
| Gurobi 版本造成性能或状态差异 | 中 | 中 | 记录版本和参数；保存问题模型；不把时间作为硬验收标准 |
| 主论文和后续论文规则混用 | 中 | 高 | 基线模块明确标记 2019 规则；后续算法不在本阶段实现 |
| 论文默认独立轮密钥，而用户误认为包含密钥编排 | 中 | 中 | README 和报告显式声明攻击模型与密钥假设 |
| 为未来 EasyBC 迁移过度抽象 | 中 | 中 | 当前接口只覆盖论文密码；复现完成后再提取稳定抽象 |
| 并行执行导致日志或缓存冲突 | 中 | 中 | 每个任务独立输出目录；首版串行，服务器采用进程级任务拆分 |

### 11.1 已发现的重点疑点

主论文在 SIMON 的 CBDP-MILP 描述中将 XOR 约束写为类似

\[
a^{i+1}_j-b^i_j-t^i_j-w^i_{(j-2)\bmod n}=1.
\]

按照论文此前给出的 XOR Model 2 和 SIMON 轮函数语义，右端疑似应为 0。实施时必须：

1. 从基本 Copy/AND/XOR division transition 独立构造单轮模型；
2. 枚举小规模输入输出检查模型；
3. 对比使用右端 0 和 1 时的合法 transition；
4. 将最终采用形式和证据写入 `paper-errata.md`。

在完成验证前，不直接假定论文或当前判断必然正确。
