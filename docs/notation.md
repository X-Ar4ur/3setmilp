# 符号、位序与初始 BDPT 约定

本文档记录实现采用的数学约定。任何密码模型都必须遵守这些约定，不能在局部模块中隐式改变位序。

## 1. 内部位向量表示

宽度为 \(n\) 的向量写为

\[
u=(u_0,u_1,\ldots,u_{n-1}).
\]

内部使用非负整数保存向量，其中分量 \(u_i\) 对应整数的第 \(i\) 位：

\[
\operatorname{encode}(u)=\sum_{i=0}^{n-1}u_i2^i.
\]

因此，论文从左到右打印的向量 `[1,0,0,0]` 在内部整数表示中是 `0b0001`，而不是通常阅读二进制字符串时的 `0b1000`。

该约定只定义抽象向量索引。SIMON 的左右分支、旋转方向以及论文十六进制输出将在密码模型中通过显式 state layout 映射，不在此处预设。

## 2. 逐位偏序

对两个等宽二进制向量 \(a,b\)，定义

\[
a\succeq b \iff \forall i,\ a_i\ge b_i.
\]

整数 bitset 中等价于：

```text
(a & b) == b
```

严格支配表示 \(a\succeq b\) 且 \(a\ne b\)。

## 3. BDPT 三值语义

状态 \(D_{K,L}^{1^n}\) 对指数向量 \(u\) 的语义为：

1. 若存在 \(k\in K\) 使 \(u\succeq k\)，结果为 unknown；
2. 否则若 \(u\in L\)，结果为 1；
3. 否则结果为 0。

这一判断顺序很重要：即使 \(u\in L\)，只要它同时位于某个 \(k\) 的上闭包中，结果仍是 unknown。

## 4. Reduce0 与 Reduce1

若 \(k,k'\in K\) 且 \(k\succeq k'\)，则 \(k\) 的 unknown 上闭包已经被 \(k'\) 覆盖，可以删除 \(k\)。

若 \(\ell\in L\)、\(k\in K\) 且 \(\ell\succeq k\)，则 \(\ell\) 对应结果已经是 unknown，可以从 \(L\) 删除。

## 5. 选择明文集合的初始状态

设活动位索引集合为 \(I\)，活动位遍历全部 \(2^{|I|}\) 个取值，其他位是固定但攻击者在抽象描述中未指定取值的常量。记 \(u_I\) 为仅在 \(I\) 上取 1 的向量。

直接穷举所有常量赋值可得到：

- \(u_I\) 的 parity 始终为 1，因此 \(L=\{u_I\}\)；
- \(u_I\) 的任意严格超集会随常量赋值取 0 或 1，因此属于 unknown；
- 其他指数向量的 parity 始终为 0。

规范化后的最小 \(K\) 为

\[
K=\{u_I\lor e_j\mid j\notin I\}.
\]

论文中 SIMON32 只有一个常量位，所以得到

\[
K=\{(1,1,\ldots,1)\},\qquad
L=\{(0,1,\ldots,1)\}.
\]

实现同时保留两个相互独立的方法：

- 穷举所有具体常量赋值得到三值状态；
- 使用上述公式直接构造三值状态。

单元测试要求两者在小维度下完全一致。这样可以在不依赖传播规则和 MILP 的前提下验证初始 BDPT。

## 6. 当前尚未固定的密码级约定

SIMON 状态已经依据主论文第 413--415 页的公式和 \(Q_{1,15}\) 示例确定：

- 内部低 \(n\) 位依次保存 \(x_0,\ldots,x_{n-1}\)，高 \(n\) 位依次保存 \(y_0,\ldots,y_{n-1}\)；
- 论文状态字符串按 \(x_{n-1},\ldots,x_0,y_{n-1},\ldots,y_0\) 打印；
- 循环左移 \(r\) 位后的输出第 \(j\) 位来自输入第 \((j-r)\bmod n\) 位；
- 局部核心 \(Q_{i,j}\) 的 4-bit 顺序为 \((x_{j-1},x_{j-8},x_{j-2},y_j)\)。

主论文约束 \(L_3\) 的右端 `1` 已确认与 XOR Model 2 矛盾，实现采用右端 0；证据见 `paper-errata.md`。

## 8. Table 5 的 SPN 打印顺序

局部函数公式中的 \((x_0,\ldots,x_{63})\) 是坐标列举，不能直接推断 Table 5 字符串的显示方向。结合各密码规范的状态布局，实验使用：

- PRESENT：按主论文第 5.2 节列出的 \(x_0,\ldots,x_{63}\) 打印；PRESENT60 的四个预期 balanced 位为内部索引 51、55、59、63；
- RECTANGLE：依次打印 row0、row1、row2、row3，每行按 column15 到 column0；第一个预期 balanced 分量对应内部索引 15，第一组最后一个分量对应内部索引 0；
- SIMON：按左右字高位到低位打印；
- LBlock：按 \((x_{31},\ldots,x_0,y_{31},\ldots,y_0)\) 打印。

实验脚本为每个密码保存显式的打印位置到内部索引排列，不能共用简单的全局字符串反转规则。
